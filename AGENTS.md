# HATTORI AI Assistant

## О проекте

HATTORI — AI-ассистент для барбершопа.

Основные интеграции:
- WhatsApp через GreenAPI
- Altegio
- OpenAI
- внутренняя база данных
- сайт
- Instagram

## Главное правило

Всегда следовать утверждённому техническому заданию проекта.

Не придумывать бизнес-правила самостоятельно.

## Altegio

Altegio является источником истины по:
- услугам
- ценам услуг
- мастерам
- расписанию
- свободным слотам
- фактическим записям

Не создавать отдельный календарь записи внутри нашей системы.

## Состояния записи

Используются состояния:
- SELECTED
- BOOKED
- CONFIRMED
- COMPLETED
- CANCELLED
- NO_SHOW

SELECTED не резервирует слот.

BOOKED может быть создан только после явного подтверждения клиента.

## Ограничения AI

Ассистент не должен придумывать:
- цены
- услуги
- скидки
- акции
- свободные окна
- внутренние правила HATTORI

Если информации нет, нужно эскалировать вопрос человеку, а не угадывать ответ.

## Учёт визитов

Счётчик визитов увеличивается только для COMPLETED.

Не считаются визитами:
- CANCELLED
- NO_SHOW
- перенос записи

## Ручное вмешательство

Если включено ручное вмешательство:
- AI не отвечает
- автоматические сообщения не отправляются
- запланированные сообщения не отправляются

## Надёжность

Внешние события должны обрабатываться идемпотентно.

Повторная доставка одного и того же события не должна приводить к:
- двойной записи
- двойному сообщению
- двойному бонусу

## Правила разработки

Перед изменением кода:
1. Прочитать этот файл.
2. Понять существующую структуру проекта.
3. Делать минимально необходимое изменение.
4. Не переписывать несвязанный код.
5. Добавлять или обновлять тесты.
6. После изменений запускать тесты.
7. Сообщать, какие файлы изменены.
8. Не менять архитектуру без явного запроса.
9. Не добавлять новые зависимости без необходимости.
10. Не хранить секреты и API-ключи в репозитории.
